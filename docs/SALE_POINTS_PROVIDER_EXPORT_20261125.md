# نقاط البيع والتصدير لمزود الكروت — 25 نوفمبر 2026

## نقاط البيع
- صفحة «إدارة الكروت ← نقاط البيع والمزودون» (`/vouchers/sale-points`): اسم ونوع (نقطة بيع/كشك، محفظة إلكترونية، مزود كروت، أخرى) وملاحظة،
  مع عدد الحزم والكروت وغير المستخدمة لكل نقطة.
- تظهر الأسماء النشطة اقتراحات في حقل «نقطة البيع» عند إنشاء الحزمة وتعديلها؛ الحقل يبقى نصًا حرًا كما سابقًا، فلا ترحيل للحزم القديمة.
- تعديل الاسم يحدّث الحزم التي تحمل الاسم القديم؛ الإيقاف يخفي الاسم من الاقتراحات فقط. الإدارة لمدير الشبكة (الموزع يرى فقط).
- بذرة مرة واحدة: «توزيع عام» و«كروت الشبكة (tabweeb)» (مزود). المبيعات في التقارير تُجمع بهذه الأسماء.

## التصدير لمزود الكروت (مثل kurootalshabakah.tabweeb.com.ye)
من قائمة إجراءات الحزمة (صلاحية `vouchers.print`):
- **للمزود: PDF مربعات الكروت** — شبكة 4×12 (48 كرتًا في صفحة A4)، كل مربع فيه رمز الكرت فقط بخط ثابت، بلا شعار أو سعر أو QR أو عناوين.
- **للمزود: Excel كرت في كل صف** — بلا صف عناوين، الرمز نصًا (تبقى الأصفار البادئة).
- الكروت **غير المستخدمة فقط** وبترتيب السيريال؛ الكروت المفعّلة تُستبعد ويُذكر عددها بعد التنزيل.
- كرت الرمز الواحد (PIN أو كلمة المرور = الاسم): قيمة واحدة. إن اختلفت كلمة المرور: سطر ثانٍ في المربع وعمود ثانٍ في Excel.
- اسم الملف: اسم ملف الحزمة المعتاد مع `-مزود`. كل تصدير في سجل التدقيق (`PROVIDER_EXPORT`).
- التكامل عبر API مع المزود لاحقًا إن توفرت واجهة.
